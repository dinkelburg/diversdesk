Release Date: June 29, 2026

## What This Release Improves

Today's live release is headlined by **refund handling directly inside Diversdesk**, including refunds for payment gateway payments.

Alongside that, this release also includes several booking, planning, surcharge, and webshop workflow improvements.

---

### Refunds handled directly in Diversdesk

Refund flows are now available inside Diversdesk itself. This includes payment gateway refunds, so you can manage the refund process directly from the dashboard instead of depending on a separate back-and-forth workflow outside Diversdesk. For teams handling customer changes, cancellations, or corrections, this makes refund handling much more practical and much easier to stay inside one operational flow.

### Faster scheduling and rescheduling

Scheduling now requires less repetition. When adding or rescheduling an activity, participants are automatically selected, and same-activity scheduling is faster. This chips down several manual steps from common day-to-day planner work and helps staff move through repeated scheduling activities more quickly.

### Clearer surcharge handling

Surcharge amounts can now be rounded more cleanly, and the summary section gives a better overview before you confirm changes. Together, those changes make surcharge handling easier to review and easier to explain, especially in bookings where operators want a cleaner final amount before saving.

### Better control over webshop availability

You can now block specific days to prevent webshop bookings for selected activities, making availability management more precise. This gives teams more direct control over when an activity should stay unavailable online without needing broader workarounds.

### Easier tiered pricing day handling

Day multiplier support now makes it easier to add days to tiered-priced activities without manually reworking the dive setup each time. Operators can define the daily dive amount and then quickly add extra days, with the related dives scaling along with that choice. This makes tiered activity setup faster and more consistent, especially when working with longer or flexible multi-day bookings.

### Improved shared-tablet checkout flow

The shared-tablet checkout flow now adds an extra way to properly end a session. This is especially useful in front-desk or registration situations where multiple participants use the same tablet one after another. Previously, an active browser session could remain in place and interfere with the next registration flow. This update helps staff reset that experience more cleanly between participants.

### Clearer day-card warnings in activity editing

This release also improves the warning shown when changing day-card selections in the activity edit side panel. Before, moving an activity away from a past date could still trigger a warning based on the old date, even when the newly selected date was in the future. The warning now better reflects the actual new selection, making activity editing feel more logical and less confusing.
