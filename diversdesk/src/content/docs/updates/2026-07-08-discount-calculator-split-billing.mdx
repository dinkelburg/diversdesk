<p class="update-release-date">Release Date: July 8, 2026</p>

This release introduces two major billing improvements in Diversdesk: the new **Discount Calculator** and **Split Billing**.

Together, these updates make it easier to apply structured discounts, review pricing before confirming changes, and divide booking charges more clearly when more than one guest or payer is involved.

This release also improves **return customer scheduling**, which can now be handled in bulk and is therefore much faster for repeat operational workflows.

---

## Updates in This Release

* **Rule-based discount calculator:** replace the old single discount field with reusable discount logic.
* **Flexible discount targeting:** apply discounts to the full booking or to selected participants.
* **Support for fixed amounts and percentages:** use the format that fits the booking scenario.
* **Clearer totals preview:** review pricing changes, warnings, and customer-facing outcomes before confirming.
* **Split billing workflow:** divide charges more clearly when a booking needs to be shared across multiple parties.
* **Better internal and customer visibility:** preview how split charges will affect totals and billing presentation.
* **Faster return customer scheduling:** handle repeat-customer scheduling in bulk instead of repeating the same steps one by one.

---

### Discount Calculator is now live

The new **Discount Calculator** replaces the previous one-field booking discount flow with a more flexible rules-based workflow.

This makes it easier to manage repeat discount scenarios without rebuilding the same setup each time. Teams can create more structured discounts, choose where they apply, and confirm the pricing effect before saving the change.

In practice, this helps reduce manual rework and makes discount handling easier to understand during live booking changes.

You can read the full setup and usage guide here: [Discount Calculator](/features-resources/discount-calculator).

### Split billing for shared charges

The new **Split Billing** workflow is now available for bookings that need charges divided more clearly.

This helps when billing needs to be shared across participants, booking lines, or other booking elements, while still keeping the total picture easy to review internally.

By previewing how charges are split before final confirmation, your team gets a clearer view of the booking outcome and a more predictable billing workflow.

### Faster bulk scheduling for return customers

Scheduling **return customers** has also been improved in this release.

This flow can now be handled in bulk, which makes repeat scheduling work much faster for teams that regularly rebook familiar guests across activities or dates.

Instead of repeating the same actions customer by customer, staff can move through return-customer scheduling with less manual effort and a more efficient day-to-day workflow.
