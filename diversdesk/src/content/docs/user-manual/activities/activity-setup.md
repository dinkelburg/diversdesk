Use this guide as your operational checklist when creating a new activity and preparing it for the webshop.

This article focuses on setup flow and decision points.

For pricing-specific configuration, see [Pricing](/user_manual/activities/pricing/).

## Recommended Setup Order

1. Define or confirm the category where the activity should appear.
2. Create the activity with complete operational details and customer-facing content.
3. Configure pricing and any pricing variations.
4. Review publication state.
5. Decide whether to feature the activity on the webshop landing page.
6. Verify webshop presentation in manager view before exposing to customers.

## Category Decisions Before You Create

Before creating the activity, decide:

- Which category best matches customer intent
- Whether the activity should be discoverable through category browsing only, featured placement, or both
- Whether it is a permanent offering or a seasonal/promo item

Good category structure reduces customer confusion and keeps landing-page browsing clear.

## Publication and Visibility Behavior

- Published activities can appear for customers in public webshop view.
- Unpublished activities do not appear to customers.
- Managers can still see unpublished activities in manager view (visually faded), which is useful for temporary deactivation and seasonal rotation.

## Featuring Activities

Featured activities are shown below category cards on the webshop landing page.

You can feature activities from multiple categories at the same time, which is useful for:

- Best-seller promotion
- Campaign or promo bundles
- Time-bound seasonal highlights

## Validate in Webshop Context

After setup, open [Webshop](/user_manual/activities/webshop/) in manager context and verify:

- The activity appears in the expected category
- Featured placement behaves as intended
- Unpublished/published state matches your rollout plan
