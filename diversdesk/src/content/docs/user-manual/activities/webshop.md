This manual page matches **Activities > Webshop** in the app.

Use this page when you want to manage how your activity offers are presented to customers online.

Typical use cases include:

- reviewing how activities appear in the booking flow
- adjusting how customers can select or book activity products
- checking the connection between internal activity setup and customer-facing booking options
