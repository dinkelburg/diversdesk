The **Bookings** page gives you an overview of booking records and lets you open the booking you want to work on.

Operators typically use this page to:

- locate a booking quickly
- open an existing booking for review or follow-up
- continue operational work after a booking has already been created

For a deeper explanation of the renewed booking experience, see **Our Renewed Booking Page** under **Features & Resources**.
